# RestroFly_Resturant_App 🍴

A restaurant management web app built with **Node.js**, **Express.js**, and **MongoDB**.  
This app provides user authentication, menu management, and order handling with clean REST API architecture.

---

## 🚀 Features
- 🔑 User registration & login with password hashing (bcrypt)  
- 📋 Menu management (Add / View / Update / Delete items)  
- 🛒 Place & manage food orders  
- 🗄️ MongoDB database integration with Mongoose  
- 🧾 RESTful API design  
- 🛡️ Secure middleware with validation and error handling  

---

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Mongoose ODM)  
- **Security:** bcrypt, dotenv, morgan, cors  
- **API Testing:** Postman
